Atividade 2: Incluímos CSS nos documentos HTML escrevendo em um arquivo separado com extensão .css, conectado ao HTML usando a tag , como nessa página. Ou, de forma inline ou interna.

Inline: É aplicado diretamente na tag HTML, usando o atributo style.

Interna: É aplicado dentro da tag style no cabeçalho do documento HTML.
